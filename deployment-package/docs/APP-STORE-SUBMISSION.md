Complete guide for submitting Smart Closet to the Apple App Store.

## Submission Steps

### Step 1: Prepare App Store Connect

1. Go to https://appstoreconnect.apple.com
2. Select your app
3. Click "App Information"
4. Fill in all required fields

### Step 2: Add App Metadata

1. Click "Pricing and Availability"
   - Set price (Free or paid)
   - Select territories
   - Set availability date

2. Click "App Privacy"
   - Add privacy policy URL
   - Declare data collection practices
   - Specify data usage

### Step 3: Upload Screenshots

1. Click "Screenshots"
2. For each device type:
   - Upload 2-5 screenshots
   - Add captions (optional)
   - Ensure images are correct size

### Step 4: Write Description

1. Click "General Information"
2. Fill in:
   - **Name**: Smart Closet
   - **Subtitle**: Your AI-powered personal fashion assistant
   - **Description**: See suggested copy below
   - **Keywords**: closet, fashion, AI, outfit, wardrobe, style
   - **Support URL**: Your support page
   - **Marketing URL**: Your website

### Step 5: Add Version Information

1. Click "Version Information"
2. Fill in:
   - **Version Number**: 1.0.0
   - **Copyright**: © 2026 Your Company
   - **Release Notes**: See suggested copy below
   - **Build**: Select from available builds

### Step 6: Set Rating

1. Click "Age Rating"
2. Answer questionnaire
3. System generates rating (typically 4+)

### Step 7: Submit for Review

1. Click "Submit for Review"
2. Answer compliance questions:
   - Does your app use encryption?
   - Does your app access user data?
   - Does your app use advertising?
3. Confirm submission

## Common Rejection Reasons & Solutions

### "Metadata does not match app functionality"
- Ensure description accurately reflects features
- Update screenshots to show actual app interface
- Verify keywords match app content

### "Privacy policy missing or invalid"
- Add valid privacy policy URL
- Ensure policy covers camera and photo access
- Include data retention information

### "App crashes or has bugs"
- Test thoroughly on iOS Simulator
- Test on physical iPhone via TestFlight
- Fix all crashes before resubmission

### "Misleading screenshots"
- Ensure screenshots show actual app features
- Don't use mockups or concept images
- Add captions explaining features

### "Unclear app purpose"
- Write clear, concise description
- Highlight main benefits
- Use simple language

## Appeal Process

If your app is rejected:

1. Read the rejection reason carefully
2. Fix the identified issues
3. Update app or metadata
4. Resubmit for review
5. Provide explanation in "Resolution" section
