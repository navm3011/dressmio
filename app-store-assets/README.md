## 🚀 Quick Start Guide

### For iOS Submission

1. **Read:** `iOS_SUBMISSION_GUIDE.md`
2. **Create:** Apple Developer Account ($99/year)
3. **Prepare:** Certificates and provisioning profiles
4. **Build:** Use EAS CLI to build and upload
5. **Submit:** Review and submit in App Store Connect
6. **Wait:** 24-48 hours for review

### For Android Submission

1. **Read:** `ANDROID_SUBMISSION_GUIDE.md`
2. **Create:** Google Play Developer Account ($25 one-time)
3. **Build:** Use EAS CLI to build AAB
4. **Upload:** Upload to Google Play Console
5. **Submit:** Review and submit for production
6. **Wait:** 1-3 hours for review

## 🆘 Troubleshooting

### Common Issues

**Build Fails**
- Check that all dependencies are installed
- Verify Node.js version compatibility
- Check EAS CLI is up to date

**Upload Fails**
- Verify file format (AAB for Android, IPA for iOS)
- Check file size is within limits
- Ensure bundle ID matches

**App Rejected**
- Read rejection reason carefully
- Fix the issue
- Increment version number
- Resubmit

**Screenshots Not Uploading**
- Verify image format (PNG or JPG)
- Check resolution is correct
- Ensure file size is under limit
