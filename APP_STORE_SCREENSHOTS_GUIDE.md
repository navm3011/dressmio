# App Store Connect: Screenshots & Preview Guide

This guide shows you exactly where to find and upload app preview videos and screenshots in App Store Connect.

---

## Part 1: Navigate to the Right Section

### Step 1: Go to App Store Connect

1. Go to [appstoreconnect.apple.com](https://appstoreconnect.apple.com)
2. Sign in with your Apple ID
3. Click **My Apps** (left sidebar)
4. Click on **dressMio**

### Step 2: Go to App Store Version

1. Click **App Store** (left sidebar)
2. You should see your app versions listed
3. Click on **Version 1.0** (or the current version you're working on)
4. You'll see a page with different sections

---

## Part 2: Find Screenshots Section

### Location: iOS App Previews

1. On the Version page, scroll down
2. Look for **iOS App Previews** section
3. You should see:
   - **iPhone 6.7-inch display** (for iPhone 15 Pro Max)
   - **iPhone 5.5-inch display** (for iPhone 8 Plus)
   - **iPad Pro (3rd generation)** (if you support iPad)

### If You Don't See It:

- Make sure you're on the **App Store** tab (not TestFlight)
- Make sure you're viewing a version (not a draft)
- Scroll down - it might be below other sections

---

## Part 3: Upload App Preview Video

### What You Need:

- Video file (MP4 format)
- Duration: 15-30 seconds
- Resolution: 1242 x 2208 pixels (for iPhone)
- File size: Max 500 MB

### How to Upload:

1. Under **iOS App Previews**, click **+** button
2. Select your video file
3. Wait for upload to complete
4. The preview will appear in the list

### What to Show in Preview:

- App opening/splash screen
- Main features (add items, view suggestions, save outfits)
- UI navigation
- Key functionality

---

## Part 4: Upload Screenshots

### Location: Screenshots

1. On the same Version page, look for **Screenshots** section
2. You should see device options:
   - **iPhone 6.7-inch display** (iPhone 15 Pro Max)
   - **iPhone 5.5-inch display** (iPhone 8 Plus)
   - **iPad Pro (3rd generation)**

### What You Need:

- PNG or JPG images
- Resolution: 1242 x 2208 pixels (for iPhone)
- 2-5 screenshots per device
- File size: Max 5 MB each

### How to Upload:

1. Click on a device type (e.g., **iPhone 6.7-inch display**)
2. Click **+** button
3. Select your screenshot files
4. Drag to reorder if needed
5. Add description for each screenshot (optional)

### What to Show:

**Screenshot 1:** App opening/home screen with logo
**Screenshot 2:** Add items to closet feature
**Screenshot 3:** AI analysis and suggestions
**Screenshot 4:** View saved outfits
**Screenshot 5:** Settings/profile (optional)

## Part 8: Create Screenshots from Your App

### Option 1: Use Your iOS Device

1. Open dressMio app on your iPhone
2. Navigate to each screen you want to screenshot
3. Press **Volume Up + Side Button** (iPhone X+) or **Home + Top Button** (older iPhones)
4. Screenshot is saved to Photos
5. Download to your computer
6. Resize to 1242 x 2208 if needed

### Option 2: Use Simulator (if you have Mac)

1. Open Xcode
2. Run app in iPhone simulator
3. Use **Cmd + S** to take screenshot
4. Resize to 1242 x 2208

### Option 3: Use Online Tool

1. Go to [previewed.app](https://previewed.app)
2. Upload your screenshots
3. Add mockup frames (optional)
4. Download formatted screenshots

## Part 10: Troubleshooting

### Screenshots Not Uploading

- Check file size (max 5 MB)
- Check resolution (1242 x 2208)
- Try different browser
- Clear browser cache

### Can't Find Screenshots Section

- Make sure you're on **App Store** tab (not TestFlight)
- Make sure you're viewing a version (not draft)
- Scroll down - section might be below
- Try refreshing the page

### Screenshots Look Blurry

- Check resolution (should be exactly 1242 x 2208)
- Use PNG format instead of JPG
- Increase image quality
